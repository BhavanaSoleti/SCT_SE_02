A simple number guessing game where the player tries to guess a randomly generated number within a specific range. The game provides feedback on whether the guessed number is too high or too low, and the player continues until they guess correctly.

Features
The game generates a random number within a specified range.

The player inputs their guess.

The game provides feedback after each guess: "Too high," "Too low," or "Correct!"

The player can continue guessing until the correct number is found.
